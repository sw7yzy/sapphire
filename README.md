# Sapphire Loader Setup Guide

### Getting Started

#### 1. Log Into Your Account

Go to [**https://sapphirer6.cc**](https://sapphirer6.cc) and log in using the account credentials provided by your seller.

***

#### 2. Download the Loader

Once you're logged in, navigate to [**https://sapphirer6.cc/dashboard**](https://sapphirer6.cc/dashboard)

***

### 3. Download the Loader

1. Open the downloaded loader file.
2. Wait while the installer completes the setup process.
3. When finished, you should see a message similar to:

```
Sapphire Installer
100% Loader installed at:
C:\Users\PC\AppData\Local\Sapphire\loader.exe

Press Enter to exit.
```

5. Press **Enter** to close the installer.

***

#### 4. Launch the Loader

Read the loader carefully before continuing.

Navigate to the installation location by pressing **Windows Key + R** and pasting the following directory:

```
C:\Users\YOURPCNAME\AppData\Local\Sapphire\
```

Open:

```
loader.exe
```

When prompted, paste your key into the loader.

Wait for the payload download process to complete.

#### 5. Launch the Game

Once the loader indicates that it is ready, launch **Siege**.

Follow any remaining prompts shown by the loader.

The setup process should now be complete.
