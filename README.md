# Sapphire Loader Setup Guide

### 1. Create Your Account

1. Visit the Sapphire website:
   * [https://sapphirer6.cc/](https://sapphirer6.cc/)
2. Sign up for a new account.
3. Once your account has been created, log in.

***

### 2. Redeem Your Key

1. Go to the dashboard:
   * [https://sapphirer6.cc/dashboard](https://sapphirer6.cc/dashboard)
2. Paste your key into the key redemption field.
3. Press **Redeem**.
4. Wait until the key has been successfully redeemed.

***

### 3. Download the Loader

1. After redeeming your key, press **Download Loader**.
2. Open the downloaded loader file.
3. Wait while the installer completes the setup process.
4. When finished, you should see a message similar to:

```
Sapphire Installer
100% Loader installed at:
C:\Users\PC\AppData\Local\Sapphire\loader.exe

Press Enter to exit.
```

5. Press **Enter** to close the installer.



***

### 4. Launch the Loader

1. Navigate to the installation location:

```
C:\Users\PC\AppData\Local\Sapphire\
```

2. Open:

```
loader.exe
```

3. When prompted, paste your key into the loader.
4. Wait for the payload download process to complete.



### 5. Launch the Game

1. Once the loader indicates that it is ready, launch **Siege**.
2. Follow any remaining prompts shown by the loader.
3. The setup process should now be complete.
