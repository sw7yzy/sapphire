# Save files

## How to Use Save Files

### Save File Location

The default save file directory is:

```
"C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher\savegames\{Your Account UUID}\{PRODUCT}\"
```

Replace `{Your Account UUID}` with your Ubisoft account UUID.

The `{PRODUCT}` folder depends on where you own the game:

* **Ubisoft Connect users:** `635`
* **Steam users:** `1843`

> **Important:** Ignore all `.save.upload` files. Only use files with the `.save` extension.

***

## How to Get Your Account UUID

Your Account UUID can be found through your Stats.cc profile.

1. Open **Stats.cc** in your browser.
2. Search for your Ubisoft username.
3. Open your profile page.
4. Look at the URL in your browser.

Example:

```
https://stats.cc/siege/Stompn.G2/b598e9a9-f817-42fe-b381-45f918e5efa4?addToRecents=true&playlist=ranked
```

Your Account UUID is the section after your username:

```
b598e9a9-f817-42fe-b381-45f918e5efa4
```

Use this UUID in the save file path:

```
C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher\savegames\{Your Account UUID}\{PRODUCT}\
```

***

## Uploading Save Files

To upload your save files to the server:

1. Navigate to your save file directory.
2. Select **all `.save` files** in the folder.
3. Create a post in the forum.
4. Attach all selected `.save` files to your post.

Do **not** upload `.save.upload` files.

***

## Using Save Files

To use a downloaded save file:

1. Download the save files you want to use.
2. Open your save file directory.
3. Replace your existing `.save` files with the downloaded ones.
4. Launch the game and load your save.

Make sure the files are placed in the correct directory and that the old save files have been replaced.
